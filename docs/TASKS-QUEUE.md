## Открыто, по приоритету обзора

### P1 = H1 + H2. Обработка ошибок и атрибуция роли
**Один файл, `webui/prediction_engine.py`, меняется только ветка фейла.**

- **H1.** Все классификаторы ошибок (`:409-436`) работают по подстроке `str(exc)`,
  а `httpx.ReadTimeout` в текущем стеке даёт **пустое** сообщение: таймаут не
  распознаётся ничем, `RETRY_BACKOFF_SECONDS` не применяется никогда, в
  `forecast_model_runs.error_message` пишется заглушка, фолбэк держится только на
  `break` внешнего цикла. Проверено timing'ом: 13:27:10 → 13:28:13 при timeout=60.
  Фикс: `isinstance` по `httpx.TimeoutException`/`ConnectError`,
  `openai.APITimeoutError`/`APIConnectionError`; в лог и `error_message` —
  `f"{type(exc).__name__}: {exc!r}"`.
- **H2.** `agent_role` проставляется только в успешном возврате (`:825`), в
  фейловом (`:862-869`) его нет → в БД runs 368/377 с `agent_role = NULL` и с
  `model_id` последнего *попытавшегося* кандидата. Следствие: провалы роли не
  попадают в её точность, статистика self-learning контура систематически
  оптимистична. Фикс: `agent_role=role` в фейловый результат +
  `attempted_models`/`primary_model_id`.

### P3 = M4 + M6. Гигиена цепочек
Хвост каждой цепочки — гарантированно мёртвый NVIDIA tier (`integrate.api.nvidia.com`
отвечает `410 Gone`, в истории 15+ фейлов `minimaxai/minimax-m3`) при
`strict_nvapi = False` (`:771`). Плюс нет дедупликации моделей между ролями бандла:
fallback арбитра = primary аналитика (`glm-5.1`), «второе независимое мнение»
таковым не является (`:895-940`).

### P4 = M5 + M7. Контракт и документация
Карта ролей в `AGENTS.md` расходится с прод-окружением (`OLLAMA_ANALYST_MODEL=glm-5.1`
против «analyst = deepseek-v4-pro»), и `/api/trader/forecast` (`trader_api.py:219-227`)
агрегирует точки без фильтра по роли: при выпавшем арбитре полоса строится из 2
сэмплов, бейдж остаётся `postgres`, а при одной дожившей роли `q10 = q50 = q90` —
иллюзия нулевой неопределённости при `execution_state = completed`. Требует
решения по `.env`/`AGENTS.md` и правки контракта API + UI-бейджа.
