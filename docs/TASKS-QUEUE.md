## Открыто, по приоритету обзора

### P3 = M4 + M6. Гигиена цепочек
Хвост каждой цепочки — гарантированно мёртвый NVIDIA tier (`integrate.api.nvidia.com`
отвечает `410 Gone`, в истории 15+ фейлов `minimaxai/minimax-m3`) при
`strict_nvapi = False` (`:771`). Плюс нет дедупликации моделей между ролями бандла:
fallback арбитра = primary аналитика (`glm-5.1`), «второе независимое мнение»
таковым не является (`:895-940`).

### P4 = M5 + M7. Контракт и документация
Карта ролей в `AGENTS.md` расходится с прод-окружением (`OLLAMA_ANALYST_MODEL=glm-5.1`
против «analyst = deepseek-v4-pro»), и `/api/trader/forecast` (`trader_api.py:219-227`)
агрегирует точки без фильтра по роли: при выпавшем арбитре полоса строится из 2
сэмплов, бейдж остаётся `postgres`, а при одной дожившей роли `q10 = q50 = q90` —
иллюзия нулевой неопределённости при `execution_state = completed`. Требует
решения по `.env`/`AGENTS.md` и правки контракта API + UI-бейджа.
